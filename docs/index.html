Find wasted DBUs from your Databricks system tables.

DBU Waste Finder is a free, open-source notebook (and an MCP server) that reads your Databricks system tables and lists which jobs, clusters and SQL warehouses cost the most and which look wasteful, with the DBUs involved and, where system.billing.list_prices has a price, an estimate at list price. Read-only: no data leaves your workspace.

Get the free notebook

What it checks

Top cost drivers
DBUs and list-price cost by product, job, warehouse and cluster.
Jobs on all-purpose compute
Scheduled jobs running on interactive clusters, with the list-price difference to job compute.
Cluster auto-termination
All-purpose clusters with auto-termination off or above 60 minutes.
Idle or oversized clusters
Clusters with low average CPU and memory use.
SQL warehouse auto-stop
Warehouses with auto-stop off or above 60 minutes, including ones deleted in the period.
Idle SQL warehouses
Warehouse uptime with no query running, in DBUs.
Serverless jobs
DBUs per serverless job and the share spent on failed runs.

Classic-cluster checks are tested on mock data; the warehouse and cost checks have also been run against a live trial workspace. Costs are list price, not your discount. Some SKUs have no list price; then the tool shows DBUs and marks USD as unknown.
